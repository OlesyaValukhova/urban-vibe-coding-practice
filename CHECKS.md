# Проверки приложения

| Проверка из задания | Результат |
|---|---|
| Матрица соответствует кварталам | Пройдена: 143 квартала и матрица 143 × 143; диагональ времени равна нулю. |
| Исходное состояние | Пройдена: при пустом сценарии расчёт использует только исходные население, вместимость и матрицу; остаточный дефицит — 1 025 мест. |
| Вместимость новых школ | Пройдена: добавленная вместимость отображается в квартале и отдельным KPI «Прирост вместимости». |
| Положительное целое число | Пройдена: поле не принимает нуль, отрицательное или дробное число. |
| Сброс | Пройдена: удаляет все добавленные школы и возвращает исходные показатели. |
| Карта и таблица | Пройдена: оба представления получают значения из одного результата функции `calculate`. |
| Автоподбор | Пройдена: перебирает 143 независимых вариантов, показывает ход и таблицу по убыванию сокращения дефицита. |
| Ручной и автоматический вариант | Пройдена: школа 600 мест в квартале 103 даёт такое же сокращение дефицита — 357 мест. |
